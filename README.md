# Masonic

Masonic is a small browser toy written in TypeScript that explores bricklaying structures. The app uses React with Vite and manages state through Valtio.

Bricks are rectangles connected through discrete nodes at the center of each edge. The first five bricks are placed automatically and additional bricks can be added by pressing the space bar. Connection nodes are shown as blue circles and each brick is outlined so you can see how the structure grows.
